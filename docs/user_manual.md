# User Manual

## Candidate

1. Register with required profile fields and a webcam photo.
2. Log in with the registered email and password.
3. Select a pending exam and complete identity verification.
4. Start the exam from the fullscreen readiness screen.
5. Answer questions and submit before the server-authoritative timer expires.
6. Review completed attempts and terminated-attempt reasons in history.

A genuine network outage pauses the timer and disables answers. Fullscreen exits, tab switches, face absence, and multiple faces are separate proctoring events.

## Invigilator

Use an administrator account for authorized report/export endpoints or start the optional Streamlit dashboard. Review event evidence and reports rather than treating an automated safety termination as the final disciplinary decision.
